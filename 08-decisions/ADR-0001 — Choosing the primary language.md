# ADR-0001 — Choosing the primary language

*Decision · status: proposed*

**This is the first ADR because it's the first decision, and because writing it is the point.** The manual's position: if you're comparing languages, you're procrastinating. Write this one page, commit to it, and don't reopen it for 28 weeks.

## Context

The vehicle has to satisfy two jobs at once — the learning vehicle (a language that doesn't hide the machine, so the fundamentals have something to bite into) and the interview signal (proof of depth in the market I want to work in).
