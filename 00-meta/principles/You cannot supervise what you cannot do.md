# You cannot supervise what you cannot do

*Principle · Part 6 · The Fundamentals Reset (Field Manual, Edition 2026)*

Review capability is a function of writing capability; they're the same skill pointed in different directions.

A developer who has written a thousand concurrency bugs spots the race in generated code in four seconds. One who never wrote them reads the same code and sees nothing wrong, because nothing *looks* wrong.

That asymmetry doesn't expire.
