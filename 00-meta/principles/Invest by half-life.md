# Invest by half-life

*Principle · Part 0 · The Fundamentals Reset (Field Manual, Edition 2026)*

| Knowledge type | Half-life | Example |
|---|---|---|
| Framework / library API | ~3 years | The current React data-fetching pattern |
| Language | ~10 years | Go, C#, Python |
| Systems concept | ~40 years | Cache locality, ACID, TCP, coupling |
| Reasoning skill | Career-length | Decomposition, failure analysis, tradeoff judgment |

Most developer anxiety comes from spending 90% of learning time on the top row. The top row is exactly the row AI does well, because it's the row that's fully documented, highly patterned, and low-judgment.

**Use it as a filter.** Before spending an evening on something, ask which row it's in. If it's row one, cap the time. If it's row three or four, that time compounds.
