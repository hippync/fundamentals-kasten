# Build a retrieval map, not a memory

*Principle · Part 0 · The Fundamentals Reset (Field Manual, Edition 2026)*

Don't memorize — build a retrieval map.

You don't need to hold B-tree internals in your head. You need to (a) know that index behavior is *a thing that exists and explains problems*, and (b) know the one canonical source you'd open to get precise.

Fundamentals aren't a memory game — they're a map of where the important problems live.

**This vault is that map.** Every concept note is a pin on it. The pin needs: what the thing is, what it explains, and where you'd look. It does not need to be complete.
